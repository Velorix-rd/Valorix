Frequently Asked Questions

How do I install Velorix as a desktop or mobile app?

Open Velorix in Chrome, Edge, or Safari, click the Install or Add to Home Screen button in your browser address bar.

Why does my transfer pause when switching apps?

Mobile operating systems may throttle background WebRTC connections. Keep the screen active or install the PWA for enhanced background persistence.
