Frequently Asked Questions

How does Velorix Cloud Vault encrypt my files?

Every file is encrypted client-side using Web Crypto API with 256-bit AES-GCM prior to transmission, ensuring true zero-knowledge privacy.

Can Velorix or third parties view my stored vault files?

No. Because encryption keys are generated in your local browser runtime, only recipients with your decryption passphrase can unlock the files.

Is there any file size limit in the Cloud Vault?

The Vault supports unlimited file sizes with multi-part streaming support for documents, 4K videos, archives, and datasets.
